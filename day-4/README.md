# Buổi 4 — Kết nối và chuẩn bị dữ liệu

Từ buổi này, mọi việc làm trong thư mục [`vanarsdel/`](../vanarsdel/). Buổi 4 bắt đầu bằng việc copy sản
phẩm buổi 2 và buổi 3 sang đó.

## Skill mới của buổi

`/prepare-data` — làm sạch dữ liệu và ghi lại các bước xử lý.

## Sản phẩm của buổi

| Sản phẩm | Ghi vào |
|---|---|
| Data Dictionary hoàn chỉnh, mỗi trường có trạng thái PII | `vanarsdel/knowledge/models/vanarsdel-sales/dictionary.md` |
| Dữ liệu đã làm sạch | `vanarsdel/data/clean/` |
| Bản ghi các bước xử lý | `vanarsdel/knowledge/models/vanarsdel-sales/prep-log.md` |
| File Power BI của dự án | `vanarsdel/` |

## Trước khi bắt đầu

Chạy `git pull`, mở **thư mục gốc** repo trong VSCode, cửa sổ Copilot Chat ở chế độ **Agent**. Đặt
dataset gốc vào `vanarsdel/data/raw/`.

Các bước chi tiết nằm trong tài liệu LAB buổi 4 do giảng viên phát.
