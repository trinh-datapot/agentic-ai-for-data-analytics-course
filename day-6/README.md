# Buổi 6 — Dựng semantic model (star schema) qua MCP

Làm việc trên file `.pbix` trong thư mục [`du-an/`](../du-an/).

## Skill mới của buổi

`/build-model` — dựng bảng, mối quan hệ và measure trong model qua MCP.

## Sản phẩm của buổi

| Sản phẩm | Ghi vào |
|---|---|
| Model star schema có quan hệ đúng chiều lọc, đã đánh dấu Date table | `du-an/<tên-file>.pbix` |
| Thẻ mô hình: danh sách bảng, bảng quan hệ, kết quả kiểm thử | `du-an/knowledge/models/vanarsdel-sales/model-card.md` |

## Trước khi bắt đầu

Đây là buổi đầu tiên agent thao tác trực tiếp trên Power BI qua cầu nối MCP. Bật MCP theo hướng dẫn
công cụ của khóa, mở đúng file `.pbix` của dự án, và luôn xác nhận agent đang kết nối đúng model
trước khi cho phép thao tác.

Các bước chi tiết nằm trong tài liệu LAB buổi 6 do giảng viên phát.
