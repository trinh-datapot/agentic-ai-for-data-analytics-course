# Báo cáo của bạn — Kế hoạch (buổi 3)

Một thẻ báo cáo của dự án. **Đổi tên thư mục** `bao-cao-cua-ban/` thành slug báo cáo của bạn
(ví dụ `bao-cao-hieu-qua-chi-nhanh`). Làm lần lượt bốn file, mỗi file một phần thực hành:

| Thứ tự | File | Bài |
|---|---|---|
| 1 | `analysis-requirement.md` | Bài 1 · Yêu cầu phân tích (bối cảnh báo cáo) |
| 2 | `business-questions.md` | Bài 2 · Business question |
| 3 | `report-proposal.md` | Bài 3 · Report Proposal |
| 4 | `mockup.md` (+ `mockup.html`), `review-notes.md` | Bài 4 · Mockup và xin duyệt (nghiệm thu) |

Mỗi file có sẵn khung. Thay các chỗ `<...>` bằng nội dung dự án của bạn, xóa dòng hướng dẫn khi xong.
